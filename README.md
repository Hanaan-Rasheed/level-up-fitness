# Level Up Fitness

A responsive fitness/gym website recreated from the original project screenshots.

## Features

- Responsive dark fitness website
- Home/Hero section
- Services section
- About section
- Pricing plans
- Client reviews
- Footer with social icons
- Member login page
- Basic client-side login validation
- Mobile navigation menu
- Smooth scrolling
- Responsive layout for desktop, tablet and mobile

## Project Structure

```text
level-up-fitness/
├── index.html
├── login.html
├── style.css
├── login.css
├── script.js
└── README.md
```

## Run Locally

Open `index.html` directly in a browser, or use VS Code Live Server.

## Deploy to GitHub

1. Create a new GitHub repository.
2. Upload all project files.
3. Make sure `index.html` is in the repository root.
4. Open the GitHub Pages settings and select the main branch if you want GitHub Pages hosting.

## Deploy to Vercel

Import the GitHub repository into Vercel. No build command is required because this is a static HTML/CSS/JavaScript project.

## Note

The project uses online Unsplash images and Font Awesome CDN icons. An internet connection is required for those external assets.
